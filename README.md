## 📌 Project Overview
This project analyzes over 1,300 healthcare insurance records to uncover insights about claim amounts, smoker impact, BMI trends, regional differences, and demographic patterns.  
The workflow integrates **Python for ETL**, **SQL for data querying**, and **Power BI for dashboard visualization**.

This project demonstrates my full ability to:
- Build ETL pipelines  
- Clean and transform data  
- Design relational datasets  
- Run SQL aggregations  
- Build interactive Power BI dashboards  
- Communicate insights clearly for business stakeholders  

---

## 📊 Dashboard Preview
The dashboard includes:
- Total customers  
- Average claim amount  
- Average BMI  
- Smoker percentage  
- Smoker vs Non-smoker claim comparison  
- Region-wise claim totals  
- BMI vs claim scatter plot  
- Claim by smoking status and dependents  
- Dynamic filters (region, gender, smoker status, dependents)
